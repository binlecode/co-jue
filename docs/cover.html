Two 100% First-Class Faces

No MCP wrapper needed: machine programs and humans interact on equal terms.

Machine Face (Agent-First CLI) JSON Envelope

Designed from day zero for AI agents, shell scripts, and headless automation. Zero modal prompts, deterministic behavior.

  • Single-line JSON envelope output (-j) on every verb
  • Strict 4-tier exit code taxonomy (0 ok / 1 usage / 2+ tool fail / 4 no-op)
  • Detached background playback daemon lifecycle (-d, --status, --stop)
  • Lock-free append-only listening history and durable playlist stores

Human Face (Bubbletea TUI) Dual-Column Workspaces

A high-craft Go terminal UI with responsive dual-column workspaces, synchronized lyrics, Kitty cover art, and 13 curated themes.

  • Five top-level workspaces (Search, Feeds, Queue, Playlists, History) with non-destructive state retention
  • Dual-style minimalist pixel wordmarks: calligraphic Monoline (zh) and brutalist Heavy Block (en)
  • Responsive dual-column layout: Stage list paired with an Inspector for synchronized lyrics stream
  • Full-screen Theater stage mode (F) with centered lyrics and ambient typography
  • Sub-cell progress bar, incremental filter (/), row jump (Nj), and 3-second z undo
  • In-terminal album cover art over Kitty graphics protocol with clean fallback
  • 13 built-in truecolor/ANSI themes (Catppuccin, Tokyo Night, Nord, Rose Pine, Everforest...)

Three Shipped Source Engines

Site-specific knowledge is isolated in engines; the player and TUI never change to admit new sources.

YouTube --engine yt

Direct streams via yt-dlp, quality tier mapping (low / mid / high), start offset normalization, and timestamp extraction.

Features: Search, direct stream, live streams, start offsets, transcript extraction.
Bilibili --engine bili

High-speed curl HTTP metadata extraction paired with yt-dlp stream negotiation and multi-part container (--items) traversal.

Features: Search, multi-part video paging, audio-only extraction, related recommendations.
NetEase Cloud Music --engine ne

Encrypted browser weapi protocol via openssl, real access licensing tiers (full / preview / paywalled), and synced lyrics.

Features: Encrypted search, synchronized lyrics transcript, access flags, high-bitrate audio.

Architecture & Hard Invariants

Seven standalone executables, bash 3.2 baseline, strictly locked to 5 external dependencies.

The suite refuses abstraction sprawl: mpv, yt-dlp, nc -U, curl, and jq are the only external dependencies. No C libraries, no daemon managers, no bloated MCP servers.
