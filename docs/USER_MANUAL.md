# 🎵 ting 用户使用手册（现代极简流媒体终端引擎）

> **ting（听）** 是一款面向终端的高质感、轻量级流媒体音乐与音频引擎。  
> 聚合 **YouTube**、**Bilibili（B站）** 与 **网易云音乐** 三大音源，兼具面向人类的**极简沉浸终端界面（TUI）**与面向 AI Coding Agent 的**确定性命令行契约（CLI）**。  
> 告别打开笨重浏览器与被动搜索的割裂体验 —— 终端敲下 `ting` 即可**直达你专属的账号算法推荐流**；听歌期间按 **`g`** 键即可**顺藤摸瓜展开关联推荐**；辅以**焦点行实时歌词窥探**、**1/8 亚格平滑流体进度条**、**Kitty 图形协议原生高清封面**与 **13 款现代真彩主题**。

## 1. 极速起步：一条命令开启心流

在终端里使用 ting，无需打开任何网页或应用，没有开屏广告，即开即听。

### 1.1 开箱即听：无参秒开个人推荐流

在终端中直接敲下：
```sh
ting
```
- **默认推荐流启动**：系统将自动读取配置文件记忆的默认音源（出厂默认 `yt`），并直接加载你当前浏览器账号的 **YouTube 首页算法推荐（Home Feed 20 条）**！
- 歌曲列表瞬间呈现，光标已置于第 1 首：
  - 按 **↑** / **↓**（或 Vim 键 **k** / **j**）移动光标浏览；
  - 按 **Enter（回车）**，音乐随即在后台流淌；
  - 遇到好听的歌想听更多类似内容？直接按 **`g`** 键，当前列表原地展开该视频的关联推荐（Up Next）；再按 **`g`** 瞬间恢复原列表；
  - 按 **Space（空格）** 暂停/恢复，按 **`-`** / **`=`** 微调音量；
  - 按 **`q`** 退出界面（后台播放自动安全回收，偏好自动保存）。

> *注：若尚未配置浏览器登录态或断网，界面会提示原因并平滑退回搜索输入框，按 Esc 依然能够干净退出。*

### 1.2 意图直达：带词主动搜索

如果你心里已有明确想听的歌手或曲目：
```sh
ting "周杰伦"
ting "lofi hip hop"
```
终端会跳过推荐流，直接以指定关键词向当前音源发起搜索并呈现结果。

## 2. 核心范式突破：从“纯搜索孤岛”到“推荐与漫游中枢”

传统终端播放器往往只是一个冷冰冰的“命令行搜索输入框”，用户必须先绞尽脑汁想好搜什么。听完后就陷入断流，最终不得不重回浏览器看推送、找衍生推荐。  
**ting 彻底终结了这一痛点，将流媒体最核心的“发现”与“顺藤摸瓜”完整闭环搬进终端：**

```
+-------------------------------------------------------------------------+
|                                终端漫游链路                             |
|  [直接运行 ting] ──────────────> 专属 Home Feed 算法推荐流 (免输关键词) |
|                                           │                             |
|                                           │ 按 Enter 播放               |
|                                           ▼                             |
|  [正在播放 / 任意单曲] ── 按 'g' ───────> 展开 Up Next 关联推荐列表     |
|                                           │                             |
|                                           ├─ 挑选中意曲目回车开播       |
|                                           └─ 再次按 'g' 原路秒级复原    |
+-------------------------------------------------------------------------+
```

### 2.1 开屏推荐流（Home Feed：知你所听）

- 终端运行 `ting`（或显式指定 `ting --feed home`），系统自动借用你在浏览器中已登录的 Cookie，直接提取平台根据你的历史喜好生成的个性化推荐流。
- **免重搜保护**：首屏推荐流受引擎状态机保护，按 `o` 排序或翻页时绝不会拿 `"feed:home"` 当关键词重搜；按 `e` 切换音源仅变更下一次按 `n` 搜索时的目标引擎。

### 2.2 顺藤摸瓜：`g` 键单跳关联衍生探索（Up Next）

- 在任意单曲上按下 **`g`** 键：
  - 由引擎直接调用官方 Innertube `/next` 端点，200–400ms 内原地展开 20+ 条包含作者与时长的**关联衍生推荐列表**；
  - 挑选中意曲目按 Enter 直接起播，沿着算法图谱持续向下探索；
- **单键严格可逆**：再次按下 **`g`** 键，零网络开销瞬间恢复进入前的搜索列表，**原光标与窗口绝对保真复原**！
- 底部快捷键提示栏动态按当前引擎能力展示：搜索列表中显示 `g related`，关联列表中显示 `g back to results`。

### 2.3 个人云端库一网打尽（稍后观看 / 订阅 / 历史 / 喜欢）

所有属于稳定、可分页的个人账号列表全部无缝接入 `--items` 容器动词：

| 云端库名称 | 句柄格式 | 说明 |
|---|---|---|
| **在线歌单列表 (Playlists)** | `ting-play --playlists -j` 或 TUI 按大写 **`B`** | 提取账号下全部云端歌单（支持多账号） |
| **稍后观看 (Watch Later)** | `WL` 或 `https://www.youtube.com/playlist?list=WL` | 个人暂存待看列表 |
| **已喜欢的视频 (Liked)** | `LL` 或 `https://www.youtube.com/playlist?list=LL` | 个人赞过的视频与音乐 |
| **订阅频道最新动态** | `feed:subs` 或完整 URL | 关注创作者的最近发布流（支持 500 首批量） |
| **云端观看历史** | `feed:history` 或完整 URL | 账号在全平台同步的观看收听足迹 |

在终端中只需执行例如：
```sh
# 提取当前音源账号下的在线歌单列表
ting-play --playlists -j

# 查看稍后观看列表
ting-play --items -j -- WL

# 查看订阅频道的最新视频
ting-play --items -j -- feed:subs
```

## 3. 现代 TUI 界面全景解构（一图读懂最新排版）

ting 坚守**纯单栏平铺对齐**（卡片化 NO、双栏中轴竖线 NO），将终端屏幕每一行垂直预算都发挥到极致：

```text
+-----------------------------------------------------------------------------+
| ♫ 【 听 】  query='feed:home'                         yt · 20 结果 · 质量     | <- 上带：标题、行源标识与状态段
| ▶ 播放中:   30 Years Later… We Restored the Honda NSX         【02:15/08:21】 | <- 横幅：当前在播曲目与高精度时钟
| ████████████████████▏─────────────────────────────────────────────────────── | <- 1/8 亚格平滑流体进度条
|                                                                             |
| ▎ 1. 30 Years Later… We Restored the Honda NSX                         8:21 | <- 列表区：在播整行微高亮
|   2. HONDA NSX ON THE LIMIT! // Nürburgring                           21:40 |    当前焦点强调竖条 (▎)
|   3. Build an agentic software factory: deep dive                     45:12 |    时长右贴对齐
|                                                                             |
|   Classic Car Restoration Garage · 8:21 · ad05Qt95g4w                       | <- 下带：Details 详情
|   opus 140 kbps 48.0 kHz stereo                                             | <- 音频解码规格参数
|   ♪ VTEC kicked in at 5800 RPM                                              | <- 焦点在播时：实时歌词窥探
|                                                                             |
|   ↑↓ 选择   ⏎ 播放   g 相关   / 过滤   z 撤销   q 退出   ? 键位             | <- 快捷键底栏（动态能力自适应）
+-----------------------------------------------------------------------------+
```

1. **上带（Chrome Top）**：
   - 品牌字标【听】（播放发声时光标底色动态点亮）与当前行源标识（如 `query='feed:home'` 或 `query='related:...'`）；
   - 右贴状态段：当前音源（如 `yt`）、结果总数、排序依据、登录状态；
   - 在播横幅：播放状态（播放中/缓冲中/暂停）、曲名与高精度当前时间轨；
   - **流体进度条**：满格实心块 `█` + 推进格 1/8 字符块 `▏` + 未播轨道 `─`。
2. **中带（Row List）**：
   - 最大化利用终端宽度展示完整曲名；
   - 在播行整行微高亮与光标行强调竖条（`▎`）正交独立；
   - 滚动条与时长右侧空气缓冲对齐，彻底杜绝跨终端字宽差异产生的锯齿。
3. **下带（Chrome Bottom & Details）**：
   - 焦点行 Details 区域：展示歌手/作者、发行年份、播放量、音频解码参数；
   - **歌词窥探空间**：光标停在在播行时自动置换简介展示当前句歌词；
   - 快捷键提示条：暗灰底噪，动态根据当前视图与引擎能力呈现可用按键。

## 4. 前沿微质感与视觉创新（核心特性）

### 4.1 焦点行歌词窥探（Lyric Peeking：看过去即在，移开即隐）

传统终端播放器看歌词要么切走整个屏幕（打断搜歌心流），要么硬切左右双栏（把歌名挤得全是省略号）。  
ting 独创了**行预算守恒（`Δrows = 0`）的单行内联窥探**：

- **聚焦即来**：光标停在正在播放的那首歌上，下方的曲目简介（Description）会自动**等额置换**为当前正在演唱的那一句歌词；
- **移开即隐**：光标一旦移动到其他歌曲，歌词瞬间隐退，原歌曲简介立即复原；
- **换句微过渡**：换到下一句歌词时，内置 **150ms 柔和亮度呼吸微动效**（Accent Bold 过渡），告别机械顿挫；
- **间奏呼吸提示**：前奏未起或长间奏 solo 期间，弱化显示 `♪  · · ·`，直观确认音乐平稳流动；
- **纯音乐与无词优雅退避**：遇到轻音乐或无字幕视频，完全不报红字，安静退回普通简介；
- **会话级零流量缓存**：一首歌只要解析过一次字幕，在内存中终身保留，来回移动光标零重复网络请求。

### 4.2 1/8 亚格平滑进度条（Sub-cell Progress Bar）

不再忍受每 4~8 秒猛跳一格的粗糙进度条！ting 引入了基于 Unicode 8 分之 1 字符块（`▏▎▍▌▋▊▉`）的亚格渲染：

- **0.6 秒连续流动感**：在 60 列标准宽度下，配合单调时钟线性外推（Dead Reckoning），进度条每 0.6 秒平滑推进 1/8 字符，呈现出原生桌面 GUI 播放器般的丝滑感；
- **章节断口保护**：在播带有分段章节的音频时，章节边界在进度条上精准镂空断开，且推进格绝不覆盖章节空格标记；
- **ASCII 模式纯净回退**：在 `TING_ASCII=1` 环境下，自动平稳降级为整格 `=` 与 `-` 步进。

### 4.3 终端高画质专辑封面（Kitty 图形协议原生发射）

ting 支持在现代终端（如 **Kitty**、**Ghostty**、**WezTerm** 等）中直接展示高分辨率专辑封面！

- **原生 Kitty 协议**：无需安装外部 `chafa`、`ueberzug` 或依赖 mpv 弹窗，由 ting 纯 Go 原生解码（支持 JPEG、PNG、WebP）并计算单元格几何直接向终端发射图像；
- **Inspector 侧栏与 Details 嵌入**：在宽屏（≥96 列）下，封面独占右侧 Inspector 检查器顶部，与实时同步歌词并列；在标准/紧凑宽度下，封面静置于右侧详情区域，不抢占主歌曲列表行宽；
- **全行源统一覆盖**：搜索流（`w1`）、算法推荐流（`w2`）、在线云端歌单库与内部曲目（`B`）、本地播放列表（`b` / `w4`）、待播队列（`u` / `w3`）、多 P 视频（`c`）、分章节（`i`）与关联推荐（`g`），只要光标聚焦对应项，右侧即刻实时呈现对应封面；
- **自适应开关**：支持 `auto`（检测到兼容终端自动开启）、`on` 或 `off`（`TING_IMAGE=off`）。

### 4.4 13 套现代主题与真彩三层灰阶（`t`）

告别刺眼的粗劣 ANSI 色块。ting 原生支持 24-bit TrueColor，严格收敛为**三层灰阶视觉层次**：
- **Foreground（前景焦点）**：当前光标行标题与发声歌词（Bold + Accent 强调色）；
- **Secondary（次要信息）**：时长、分 P 数、排序依据（中灰阶 Muted）；
- **Tertiary（环境底噪）**：快捷键说明、滚动条、分割线（极暗灰阶 Subtle）。

按键盘 **`t`** 键可在 13 套流行配色间无缝实时轮换：
`minimal`（极简清爽）→ `catppuccin`（经典暖柔）→ `tokyonight`（东京之夜）→ `gruvbox`（复古大地）→ `rosepine`（粉灰优雅）→ `nord`（极光冷调）→ `kanagawa`（神奈川和风）→ `everforest`（常青森林）→ `onedark`（Atom 经典）→ `monokai`（明快活力）→ `solarized`（护眼调）→ `dracula`（吸血鬼紫）→ `mono`（黑白极简）。

按 **`l`** 键可一键切换中英文界面。

## 5. 键盘交互心流与日常操作指南

ting 坚持**零模态即时操作**：界面永远不会弹窗打断心流问你“你确定要删除吗？”，所有误触全部通过 **`z` 键 3 秒撤销**兜底。

### 5.1 常用快捷键完整速查卡

### 5.2 一个视图，八大行源（可逆双向键位：`g` / `b` / `B` / `h` / `c` / `i` / `u`）

ting 采用统一渲染器，所有非搜索内容均作为**临时替换行源**接入，遵循**“按哪个键进入，就按哪个键原路返回”**的直觉契约：

- **关联推荐（`g`）**：在支持的音源（如 YouTube）单曲上按下 `g`，展开该视频的 Up Next 关联衍生推荐，挑中回车直接开播；再按一次 `g` 原路退回搜索结果；
- **本地歌单（`b`）**：按下 `b` 查看所有本地自建歌单；选中歌单回车展开曲目；再按一次 `b` 原路退回搜索结果；
- **在线歌单（`B`）**：按下大写 `B` 提取当前音源账号下的在线歌单（如 YouTube 的 Liked videos、Watch later 及自建歌单），直接以主舞台行源呈现；上下键选择回车展开；再按 `B` 或 `Esc` 原路退回；
- **收听历史（`h`）**：按下 `h` 查看最近播放历史，再按 `h` 瞬间返回；
- **视频分 P（`c`）**：在 B 站等多 P 视频上按 `c` 展开分集列表，再按 `c` 原路返回；
- **分段章节（`i`）**：在油管或带时间轴的长音频上按 `i` 展开章节（如 `03:20 第一章`），光标随播放进度自动同步；再按 `i` 返回；
- **待播队列（`u`）**：按下 `u` 打开当前播放器队列，可对等待中的曲目按 `x` 移出、按 `X` 清空、或用 `p` / `P` 调整顺序，再按 `u` 返回；
- **外部粘贴（URL）**：粘贴外部专辑/合集链接自动展开为只读容器行，按 `b` 或 `B` 原路退出。

> **零网络开销返回**：返回刚才的搜索列表走的是内存快照暂存，零网络往返延迟，原光标与翻页位置绝对保留。

### 5.3 跨平台一键轮换音源（`e`）

在搜索结果页面，按下 **`e`** 键即可在三大平台间即时轮换：
`YouTube (yt)` → `Bilibili (bili)` → `网易云音乐 (ne)`。无需重新打字，ting 会自动用当前搜索词向新音源发起并发检索。

### 5.4 播放模式与解码形态（`r` / `v` / `f`）

- 按 **`r`** 键切换循环规则：
  1. **`off`（单曲播放）**：播完当前一首后自动静默停播；
  2. **`seq`（顺序连播）**：从当前光标处开始，将后续列表作为连续队列顺次播放；
  3. **`one`（单曲循环）**：单曲播放完毕自动重头循环。
- 按 **`v`** 键切换解码呈现形态：
  - `audio`：纯音频流播放（默认，极省 CPU 与带宽，适合办公编码）；
  - `video`：打开独立 mpv 高清视频窗口播放；
  - `fast`：低缓冲快速视频模式。
- 按 **`f`** 键切换音频品质：
  - `auto` → `medium` → `high`（最高音质）。

### 5.5 零阻断心流与 3 秒撤销安全兜底（`z` 机制）

- **移出歌曲（`d`）**、**删除整单（`D`）**、**队列移除（`x`）**：按下瞬间操作立刻完成，绝无弹窗打断！
- **后悔药（`z`）**：操作发生后的 3 秒内，屏幕提示栏会常驻显示 `z 撤销`。在这 3 秒内按下 **`z`** 键，删除的内容立刻原状恢复；
- **副作用挂起**：如果你删除了正在播放的那首歌，停播动作会挂起推迟 3 秒执行——只要你在 3 秒内按 `z` 撤销，当前正在播放的声音**完全不会被掐断**！

### 5.6 实时过滤与剪贴板链接智能识别（`/` 与 `p`）

- **即打即显过滤（`/`）**：
  在任意曲目列表下按下 `/` 键，输入拼音、汉字或英文单词，列表实时过滤出匹配项。按 `Esc` 退出过滤恢复全量列表。
- **全局智能粘贴识别（`p` 或 `Ctrl+V` / `Cmd+V`）**：
  在主界面、过滤框或搜索提示中直接按下 `p` 或系统粘贴快捷键：
  - 自动识别网址，智能剔除客户端分享文本（如 B 站 `【视频标题】` 或网易云 `分享单曲:` 杂质）；
  - **粘贴单曲链接**：自动解析该曲目并高亮展示在列表中（按 `b` 可返回原搜索），回车直接开播；
  - **粘贴歌单/合集链接**：自动展开整张歌单（只读视图），按回车任选播放，按 `b` 退出。

### 5.7 Vim 级绝对行号与精准跳转（`#` 与 `Nj`）

- 按键盘 **`#`** 键，曲目前方会显示全局绝对行号（如 `1.`、`2.`、`12.`）；
- 支持 Vim 组合跳转：例如敲入数字 `1` `2` 再按 `j`（即 `12j`），光标会直接瞬移到第 12 行。

## 6. 进阶玩法：后台脱离与命令行控制（Agent 契约面）

ting 具备强大且严苛的 **Agent / CLI 契约面**。所有功能均可完全脱离 TUI 界面，由命令行脚本或 AI Coding Agent 直接驱动。

### 6.1 终端关闭也能听：后台脱离播放（`ting-play -d`）

使用 `-d`（detach）参数启动后台播放：

```sh
# 后台播放 YouTube 视频音频
ting-play -d -- "https://www.youtube.com/watch?v=ad05Qt95g4w"

# 后台播放网易云单曲
ting-play -d -- "https://music.163.com/song?id=1824020871"

# 后台播放 B 站视频音频
ting-play -d -- "https://www.bilibili.com/video/BV1xx411c7mD"

# 后台播放指定音源的搜索关键词
ting-play -d --engine ne -- "反方向的钟"
```
敲下回车后命令在毫秒级内返回并交出进程控制权，终端窗口关掉、电脑休眠唤醒后音乐依然平稳播放。

### 6.2 实时状态监控与播放器无缝接管机制

```sh
# 1. 查看当前所有后台播放器的实时状态（支持单行 JSON -j 输出）
ting-play --status -j

# 2. 暂停与恢复
ting-play --pause
ting-play --resume

# 3. 调节音量（0 - 100）
ting-play --set-volume 80

# 4. 前进后退（相对跳转）或绝对定位
ting-play --seek +30
ting-play --seek -15
ting-play --seek-to 120

# 5. 停止播放（多播放器时带 --id 或 --all）
ting-play --stop
ting-play --stop --all
```

> **无缝接管机制**：若后台已运行着 `ting-play -d`，此时在终端启动 `ting` TUI 界面，系统会**自动捕获并无缝接管**正在播放的声音（横幅自动亮起、时钟自动对齐），退出 TUI 时也不会误杀原有声音。

### 6.3 推荐流、在线歌单与关联推荐 CLI 动词（`--feed`、`--playlists` 与 `--related`）

```sh
# 1. 获取 YouTube 账号首页推荐流（单行 JSON 信封，20 条）
ting-play --feed home -j -n 20

# 2. 提取当前音源账号下的在线歌单列表（大写 B 对应的底座动词）
ting-play --playlists -j -n 50

# 配合 --account 指定所用多账号邮箱或 authuser 序号
ting-play --playlists --account bin.le.code@gmail.com -j

# 3. 毫秒级提取指定单曲的 Up Next 关联推荐
ting-play --related -j -n 10 -- ad05Qt95g4w

# 4. 提取稍后观看 (WL) 或订阅更新 (feed:subs) 容器
ting-play --items -j -- WL
ting-play --items -j -- feed:subs
```

### 6.4 待播队列管理与管道编排（`--queue -`、`ting-history`）

```sh
# 查看最近播放的 10 条历史
ting-history --ls -n 10

# 管道神技：将最近听过的 20 首歌直接作为新播放队列起播
ting-history --ls -n 20 -j | ting-play -d --queue -

# 管道神技 2：将推荐流直接管道输入后台连续播放
ting-play --feed home -n 10 -j | ting-play -d --queue -
```

### 6.5 终端频谱与波形可视化（`-f viz`）

在终端中启动音频可视化窗口，伴随律动实时渲染 ASCII 频谱：

```sh
ting-play -f viz -- "https://www.youtube.com/watch?v=ad05Qt95g4w"
```
- 支持柱状图 `bars` 与波形图 `wave`；
- 支持自定义颜色 `--viz-color cyan/magenta/green`，按 `q` 退出。

## 7. 账号关联与个人偏好配置手册

### 7.1 自动记住你的操作（11 个偏好键就地写回）

在 `ting` 界面中切换主题（`t`）、语言（`l`）、音源（`e`）、排序（`o`）、循环（`r`）、行号（`#`）、列表模式（`Tab`）或音质时，**退出时 ting 会自动将这些更改写回你的用户配置文件**，下次开机自动生效。

### 7.2 关联浏览器登录状态与多账号切换（`TING_COOKIE_ACCOUNT` 与 `--account`）

B 站、网易云等对游客用户限制了最高音频码率，而 YouTube 首页推荐与稍后观看需要登录态。如果你已在系统浏览器中登录了对应平台，ting 支持免鉴权直接借用浏览器 Cookie：

```ini
# 借用 Chrome 浏览器登录凭据（亦可填 edge, safari, firefox, brave 等；设为 none 为纯匿名）
TING_COOKIE_BROWSER=chrome
```

#### 💡 多 Google 账号无缝切换（指定首选账号）

如果你的 Chrome 浏览器中同时登录了多个 Google / YouTube 账号（例如工作账号与个人日常账号），系统默认会使用第 1 个登录的主账号（`authuser=0`）。

ting 支持通过 **邮箱地址** 或 **数字序号** 精准指定你听歌的首选账号：

1. **配置文件永久生效（最推荐）**：
   在 `~/.config/ting/config` 中设置：
   ```ini
   # 直接填写你要使用的 Google 账号邮箱（自动匹配 Chrome 登录态）：
   TING_COOKIE_ACCOUNT=bin.le.code@gmail.com

   # 或者直接填写 Google authuser 序号（0, 1, 2...）：
   # TING_COOKIE_ACCOUNT=1
   ```
2. **命令行参数临时指定**：
   ```sh
   # 启动 TUI 时单次指定账号
   ting --account bin.le.code@gmail.com
   ting --account 1

   # CLI 工具调用时指定账号
   ting-play --feed home --account bin.le.code@gmail.com -j
   ting-play --playlists --account 1 -j
   ```
3. **终端环境变量会话生效**：
   ```sh
   export TING_COOKIE_ACCOUNT="bin.le.code@gmail.com"
   ting
   ```

#### 🔍 如何查看本机 Chrome 已登录的全部 Google 账号序号？
在终端运行以下一行命令，即可列出 Chrome 默认配置中已登录的全部账号及对应序号：
```sh
jq -r '.account_info[] | "\(.email)"' "$HOME/Library/Application Support/Google/Chrome/Default/Preferences" 2>/dev/null | nl -v 0
```
你可以随时通过 `ting-play --auth` 校验当前生效的账号与绑定状态：
```sh
$ ting-play --auth
cookie (chrome, account: bin.le.code@gmail.com, authuser: 1)
```

### 7.3 推荐常用配置模板（~/.config/ting/config）

用户配置文件位于 `~/.config/ting/config`（若不存在可直接创建）：

```ini
# 默认启动音源：yt（YouTube）、ne（网易云）、bili（B站）
TING_DEFAULT_ENGINE=yt

# 借用哪个浏览器的登录态（开启专属推荐流与高码率）
TING_COOKIE_BROWSER=chrome

# 首选 Google/YouTube 账号（支持直接填邮箱或填 authuser 序号 0, 1...）
TING_COOKIE_ACCOUNT=bin.le.code@gmail.com

# 默认主题皮肤（推荐 minimal, tokyonight, nord, rosepine, catppuccin）
TING_THEME=tokyonight

# 界面语言：zh（中文）或 en（英文）
TING_LANG=zh

# 默认音质档位：auto（自适应）、medium（中等）、high（最高音质）
TING_PLAY_QUALITY=high

# 每次搜索与推荐拉取条数
TING_SEARCH_RESULTS=20

# 列表展示模式：scroll（连续滚动）或 page（固定分页）
TING_LIST_MODE=scroll

# 终端专辑封面显示：auto（自动检测兼容终端）、on（强开）、off（禁用）
TING_IMAGE=auto

# 东亚歧义字符宽度：0（默认 1 格宽，标准终端适配）、1（强制 2 格宽）
TING_AMBIG_WIDE=0
```

### 8.2 安装方式（Homebrew 或源码构建）

#### 方式一：Homebrew 一键安装（推荐）
```sh
brew install binlecode/tap/ting
# 或显式添加 tap 后安装:
# brew tap binlecode/tap && brew install ting
```

#### 方式二：克隆源码编译（跨平台通用）
```sh
# 1. 克隆代码仓库
git clone git@github.com:binlecode/ting.git ~/.ting

# 2. 构建 TUI 二进制（Go 编写，只需 Go 1.22+ 构建环境；其余均为纯 bash 3.2 脚本）

mkdir -p ~/.local/bin

for c in ting-play ting-playlist ting-history; do ln -sf ~/.ting/shell/$c ~/.local/bin/; done

# 4. 确保 ~/.local/bin 在你的环境变量 PATH 中
export PATH="$HOME/.local/bin:$PATH"
```

### 8.3 验证安装状态

在终端运行：
```sh

```
终端打印出当前版本号（如 `0.22.0`）即表明安装大功告成！

## 9. 常见问题与排错（FAQ）

### Q1: 运行 `ting` 提示 `--feed home requires a signed-in browser session`？
**解答**：
YouTube 现代网页端对未登录访客不提供个性化首页推荐流，主舞台状态栏会显示此提示。只要在 `~/.config/ting/config` 中配置已登录 YouTube 的浏览器名称（例如 `TING_COOKIE_BROWSER=chrome`），再次启动即可秒开专属推荐流！未登录状态下依然可以随时按 `n` 正常搜索全网曲目，或按 `b` 打开本地歌单、按 `h` 查阅收听历史。

### Q2: 播放开始后扬声器没有声音？
**解答**：
1. 检查当前系统音量是否静音，或在界面按 `=` 调大音量；
2. 命令行测试基础解码输出：`mpv --ao=null` 是否正常，Linux 检查 PulseAudio / PipeWire 守护进程；
3. 执行 `ting-play --stop --all` 清理可能遗留的僵尸播放进程后重试。

### Q3: 为什么网易云部分歌曲只能试听 30 秒？
**解答**：
受官方版权与 VIP 策略限制，游客未登录时网易云仅提供 30 秒试听音频。在配置文件 `~/.config/ting/config` 中配置 `TING_COOKIE_BROWSER=chrome` 借用已登录浏览器的 Cookie 即可解锁完整播放。

### Q4: 终端字符偶尔出现错位或中文字符重叠？
**解答**：
这通常是终端模拟器的中文字宽（East-Asian Ambiguous Width）判定分歧造成的：
- 推荐使用现代终端：**Ghostty**、**Kitty**、**iTerm2** 或 **WezTerm**；
- 若中文字符挤在一起，可在配置文件中设置 `TING_AMBIG_WIDE=1`；
- 若终端不支持 UTF-8 特殊符号，可在配置中加入 `TING_ASCII=1` 启用纯 ASCII 降级模式。

### Q5: 怎么一键停止所有正在响的后台音乐？
**解答**：
直接在终端敲入：
```sh
ting-play --stop --all
```
系统中由 ting 启动的所有播放进程会在瞬间被彻底干净回收。

### Q6: 如何干净彻底地卸载 ting？
**解答**：
- Homebrew 卸载：`brew uninstall ting`；
- 源码安装清理：删除 `~/.local/bin/ting*` 软链接，删除配置目录 `~/.config/ting/` 与运行时历史 `~/.local/state/ting/` 即可。
