# ting 用户使用手册：人机协同交互指南

**ting 没有独立的图形界面（GUI）或终端菜单（TUI）。你的对话窗口（或语音流）就是唯一的交互界面。**  
你不需要记任何命令行参数，也不需要看底层 JSON。本手册专门教你：**如何用最自然的人类语言，让 Agent 帮你找内容、精准研读音视频、调度端侧声音与沉淀知识资产。**

> 💡 **配套演示**：本手册已配套认知击穿交互式 HTML 幻灯片，可在浏览器中双击直接演示：[`docs/USER_MANUAL-slides.html`](USER_MANUAL-slides.html)。

## 核心心智模型 (Mental Model)

```
        人类 (你) ----------------(自然语言对话)-----------------> AI Agent (你的伙伴)
            |                                                      |         ^
            | (紧急暂停 / 即刻静音)                                 | (调度微外设) | (主动事件信标)
            v                                                      v         | events (曲毕/换章)
  物理按键 (AirPods / 键盘 F8 键) -----------------------------> ting (后台无头 mpv)
    [ 0ms 延迟 · 零 Token 开销 ]     (原生直通硬件急停)            [ 本地声卡 · 毫秒级控制 ]
                                                                      |
                                                                      +---> 触发 paused 即刻反哺 Agent
```

- **复杂意图找 Agent（语义编排通道）**：“放点适合写代码的慢歌”、“总结这期演讲第 15 分钟说了什么”、“把重点观点和时间戳记进知识库”；
- **肌肉记忆找物理键（硬件直通逃生口）**：电话来了、想立刻静音？直接轻捏一下 AirPods 耳机柄或按键盘媒体键（F8），**0ms 瞬间暂停，跳过大模型，不消耗任何 Token**；
- **下行直通与上行感知的对称闭环**：下行由人类手捏按键瞬间静音，上行由 `ting events` 即时捕获状态翻转并向智能体推送 `paused` 事件，Agent 在对话流中即刻心领神会；
- **单实例自动接力与无感续播**：每次点播新内容自动平滑替换；连续伴随播放时，通过 `ting events --until track_ended` 捕获自然放毕信号，零轮询自动接力下一首；
- **细腰微外设**：ting 仅提供极简的感知平面（`inspect` 查大纲、`transcript` 取逐字原话、`events` 主动推流信标）与执行平面（`play` 起播、`control` 播控、`status` 遥测），Agent 负责所有格式排版与交互卡片呈现。

## 常用交互场景详述与实操示范（按 ROI 价值排序）

> **场景 ROI 排序原则**：认知杠杆（长文解构、事实去幻觉、时空追问、永久资产）> 专注心流（日常伴听、细粒度播控、自动续播）> 垂直辅助（多语种歌词精读）。

### 场景 1：长视频“全局路标 ➔ 定向分章点播”联动闭环 (ROI ★★★★★)

面对动辄 2~5 小时的技术大会录播或深度播客，最有效的收听方式是：**先查大纲路标，再选感兴趣的章节精确起播**。

```
          长视频链接 (2 小时)
                  |
                  v
       【第 1 步：查全局路标】
       “这期访谈主要分哪几部分？”
                  |
     Agent 执行 ting inspect (<100 Tokens)
     输出章节地图 (Chapters)
                  |
                  v
       【第 2 步：定向分章点播】
       “第 3 章看起来很有用，直接从那章开始放”
                  |
     Agent 计算该章起始秒数 (如 18:45 = 1125s)
     执行 ting play <url> --start 1125
                  |
                  v
       从第 18:45 秒精准起播，声音直接入耳
```

#### 实操对话示例：
1. **看目录**：
   > **你**：“*看看这个 Andrej Karpathy 的新视频主要讲了啥章节？*”  
   > **Agent**：“*为您提取了章节路标：*  
   > *- `00:00` 导言与分词原理 (Tokenization)*  
   > *- `24:15` Byte-Pair Encoding 算法推导*  
   > *- `58:30` GPT-4 词表特殊 Token 陷阱*  
   > *- `1:25:10` 实践代码 Walkthrough*”
2. **点播特定章节**：
   > **你**：“*我对特殊 Token 比较感兴趣，从 58 分 30 秒直接放给我听。*”  
   > **Agent**：“*已为您从 `58:30` 起播【GPT-4 词表特殊 Token 陷阱】，耳机已就绪。*”

### 场景 2：声称级事实核查与带时间戳精读 (ROI ★★★★★)

想知道视频里到底说了什么，但不想全文读入（避免浪费上万 Tokens），也不想听机器翻译的二手幻想。

#### 实操对话示例：
> **你**：“*第 15 分钟关于 KV Cache 动态分页，作者具体怎么论证的？给出原话。*”  
> **Agent**：“*为您检索了 `14:00-17:30` 区间的原声字幕，核心结论是静态分配在高并发长文本下显存碎片化严重：*  
>   
> > [15:12] *“Static pre-allocation causes up to 70% memory waste due to fragmentation.”*  
> > — [KV Cache Optimization (15:12)](https://youtube.com/watch?v=...&t=912s)  
>   
> > [16:04] *“By introducing virtual memory paging into GPU HBM, we achieve near-zero internal waste.”*  
> > — [KV Cache Optimization (16:04)](https://youtube.com/watch?v=...&t=964s)*”

#### 关键交互点：
- **窗口相交过滤**：Agent 只切片目标 3~5 分钟的逐字字幕，上下文消耗严格锁定在 500 Tokens 以内；
- **带秒级时间戳链接**：点击链接直接跳到原视频该秒数验证原画与上下文，做到事实可核验。

### 场景 3：边听边打断的时空追问与倒带重听 (ROI ★★★★★)

一边工作一边戴耳机听背景讲座，突然听到一个关键术语但走神了 10 秒钟。

```
  [耳机里听到关键术语走神]
             |
             v
       你：“停一下，刚才那句话说了什么？”
             |
             +---> 1. Agent 立即暂停播放 (锁定当前播放头)
             +---> 2. 查 status 拿到秒数 (如 845s)
             +---> 3. 执行 transcript --range 830-850 提取原话
             |
             v
  Agent：“刚才的原话是：
         ‘具身智能的根本断层，在于端侧执行器能否在 20ms 内闭环补偿动力学扰动。’
         需要帮您倒回去 15 秒重新听一遍吗？”
             |
             v
       你：“倒回去重新听”
             |
             v
  Agent 执行 ting control seek -15 紧接着 resume，音频无缝继续流转。
```

### 场景 5：日常专注伴听、播控穿梭与自主续播 DJ (ROI ★★★★☆)

面向写代码、阅读、番茄钟工作或日常沉浸时的背景音流转。不论是网络流媒体（YouTube / 网易云）还是宿主机本地音频（如 `~/recordings/arch-review.wav`），Agent 负责挑歌、起播、呈现轻量卡片并提供全套播控与自主续播。

```
              用户意图：“放点专注写代码的 Lo-Fi，声音小点”
                                  |
                                  v
                    Agent 执行 ting play <url>
                    输出 2 行极简播放卡片 (带播放头与音量)
                                  |
            +---------------------+---------------------+
            |                                           |
    【细粒度播控与穿梭】                        【连续伴随与自动续播 DJ】
  “快进 30 秒” ➔ seek +30                   Agent 执行 ting events --until track_ended
  “跳到 14:05” ➔ seek 14:05                 曲目自然放毕 (reason=="eof") 瞬间捕获，
  “声音设为 40” ➔ volume 40                 零轮询平滑起播下一首，无缝伴听。
```

#### 实操对话示例：
1. **起播与极简卡片**：
   > **你**：“*来点适合深夜写代码的氛围音乐，音量不要太大。*”  
   > **Agent**：“*已为您起播背景音乐：*  
   > **正在播放** · Midnight Coding Chillhop · YouTube  
   > `🔊 音量 40% · 按 AirPods 耳机柄即可暂停，说“快进 30 秒 / 换一首 / 大点声”亦可控制`”
2. **播控穿梭与时空跳转**：
   - **跳过片头广告**：“*跳过前面 1 分半广告*” ➔ Agent 执行 `ting control seek +90`；
   - **细粒度回退**：“*倒回去 15 秒*” ➔ Agent 执行 `ting control seek -15`；
   - **绝对跳转**：“*跳到 24 分 30 秒*” ➔ Agent 执行 `ting control seek 24:30`（亦可绝对重置 `seek 0`）；
   - **探查进度**：“*现在播到哪了？*” ➔ Agent 执行 `ting status` 输出进度条。
3. **自主续播 DJ (零轮询开销)**：
   > **你**：“*放两首轻音乐，连续伴随播放。*”  
   > **Agent**：“*起播 Track 1。后台已设置事件信标，曲毕将为您自动无缝接力 Track 2。*”  
   *(Track 1 放完瞬间，ting events 派发 eof，Agent 即刻平滑起播 Track 2，全程 0 轮询)*
4. **工作节奏与番茄钟停止**：
   > **你**：“*专注 25 分钟，到点叫我并停掉声音。*”  
   *(25 分钟后，Agent 自动执行 ting control stop，音乐优雅停止并提醒休息)*
5. **本地录音审计**：
   > **你**：“*放一下昨天的会议录音 `tmp/meeting.wav`，从第 5 分钟开始听。*”  
   > **Agent**：“*起播本地音频：`ting play tmp/meeting.wav --start 300`，原生同态播放。*”

#### 关键交互点：
- **极简卡片**：Agent 默认只给 2 行纯净卡片，不刷屏、不堆砌无用参数；
- **音源透明**：不管是网络 URL 还是本地 WAV/MP3 文件，交互形态完全统一；
- **自动续播**：通过 `ting events --until track_ended` 捕获 `eof` 信号，避免传统轮询导致的大模型 Token 浪费与时延；
- **硬件逃生**：任何时刻用户捏按 AirPods 耳机柄或按键盘 F8 键，底层 0ms 瞬间暂停，跳过大模型。

### 场景 6：歌词同步与多语种原声精读 (ROI ★★★☆☆)

在听网易云外语音乐、或研读 YouTube 外语演讲时，随时追问当下的原声词句含义与语法。

#### 实操对话示例：
> **你**：“*现在唱的这句日文歌词是什么？翻译一下。*”  
> **Agent**：“*为您捕获当前播放头歌词原句：*  
> 🎵 **原词**：`誰にも言えない秘密を 抱えたまま歩いてきた`  
> 📖 **释义**：*一直怀揣着无法对任何人言说的秘密，就这样一路走来。*  
> 💡 **语法要点**：`〜たまま` 表示保持前项状态继续进行后项动作。*”

#### 关键交互点：
- **网易云 LRC 歌词分词**：ting 内置推导 LRC 时间戳，将逐行歌词作为结构化 cues 交付；
- **时空同步定位**：Agent 通过 `status` 读取当前播放头秒数，精准锁定目标语句，杜绝错位。

## 异常场景自愈与智能降级指南

在真实网络环境中，平台权限、字幕缺失或网络波动是常态。Agent 会根据 ting 的四级退出码与返回信封自动进行优雅降级，绝不向你抛出晦涩的底层错误：

| 现象 / 边界条件 | 底层状态码 | 根本原因 | Agent 的自愈与降级策略 |
|---|---|---|---|
| **B 站视频无公开字幕** | 退出码 4 (`unavailable`) | B 站未公开原生 CC 字幕轨 | **自动降级为 Chapters 章节地图**：“*该视频无公开原声字幕，但我为您准备好了章节路标，您可以点播特定段落直接听。*” |
| **网易云纯音乐 / 伴奏** | 退出码 4 (`unavailable`) | 纯器乐无歌词轨 | **主动标识纯音乐并照常起播**：“*这是一首纯音乐（无歌词），已直接为您在音箱起播。*” |
| **链接失效 / 暂不支持** | 退出码 1 (`error`) | 私密视频或非媒体域名 | **引导自然语言查找**：“*该链接无法直接解析。您可以直接告诉我歌名或演讲主题，我来帮您查找可用公共源。*” |
| **外部工具缺失或网络断开** | 退出码 2 (`error`) | 本地未装 mpv/yt-dlp 或断网 | **诊断性明确提示**：“*检测到底层媒体工具或网络异常，建议检查网络连接或运行 `./install.sh` 修复依赖。*” |
| **未播放时喊暂停/快进** | 退出码 4 (`not_playing`) | 播放器处于空闲状态 | **友好提醒**：“*当前没有正在播放的音频。您可以告诉我‘放首晴天’开始播放。*” |

## 终极总结口诀

- **听歌动嘴**：想听什么直接说，两行卡片看着爽；
- **暂停动手**：捏按耳机最灵光，零秒静音不用等；
- **快进快退**：报个秒数随心跳，想去哪里就去哪；
- **长篇问点**：不用通篇读字幕，报个分钟抓原话；
- **打断追问**：走神两句不用慌，倒带重听原汁尝；
- **沉淀知识**：关键证据随手存，自动归入知识库。
