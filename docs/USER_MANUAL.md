## 1. 零门槛安装：两分钟准备完毕

### 1.1 核心依赖准备

ting 底层使用了一些成熟的开源多媒体与终端工具，请先根据你的系统安装基础依赖：

#### macOS 用户（推荐使用 Homebrew）
打开系统“终端”（Terminal），复制粘贴执行以下命令：
```sh
brew install yt-dlp mpv jq curl
```
*(macOS 已经自带了 nc 网络工具，无需额外安装)*

#### Linux 用户（Ubuntu / Debian 为例）
```sh
sudo apt update
sudo apt install yt-dlp mpv jq curl netcat-openbsd openssl
```

### 1.2 一键安装 ting

#### 方式一：Homebrew 一键安装（最省心）
```sh
brew install binlecode/actop/ting
```

#### 方式二：直接克隆源码（所有系统通用）
```sh
# 1. 克隆项目到本地
git clone git@github.com:binlecode/ting.git ~/.ting

# 2. 构建界面 ting（它是 Go 程序，需要 Go 工具链；其余命令是脚本，不用构建）
cd ~/.ting && go build -o shell/.ting-go ./cmd/ting

# 3. 将四个公开命令加入个人命令路径（~/.local/bin 或 ~/bin）
#    ting-engine-* 不用链：ting-play 在自己的真实目录里找到它们
mkdir -p ~/.local/bin
ln -sf ~/.ting/shell/.ting-go ~/.local/bin/ting
for c in ting-play ting-playlist ting-history; do ln -sf ~/.ting/shell/$c ~/.local/bin/; done

# 4. 确保你的环境变量 PATH 包含了 ~/.local/bin
# （若已包含可跳过这步；若未包含，将下行写入你的 ~/.zshrc 或 ~/.bashrc）
export PATH="$HOME/.local/bin:$PATH"
```

### 1.3 检查是否安装成功

在终端输入：
```sh
ting -V
```
如果终端打印出类似 `0.10.0` 的版本号，恭喜你，安装成功！

## 2. 快速上手：只需敲一条命令

听歌非常直接，在终端中直接运行：

```sh
ting "周杰伦"
```

终端会立即原地展示搜索出来的歌曲列表！
- 按 **↑** / **↓**（或字母键 **j** / **k**）上下移动光标；
- 光标移动到想听的曲目上，按 **Enter（回车）**，音乐随即在后台流淌；
- 按 **Space（空格）** 随时暂停或继续播放；
- 按 **-**（减号）或 **=**（等号）降低 / 提高音量；
- 听完想走？按 **q** 退出界面（播放会自动干净停止）；按大写 **Q**（Shift+Q）可在退出时保持音乐在后台继续播放！

如果你只想先打开播放器再搜歌，直接敲：
```sh
ting
```
界面会弹出一个搜索框，敲入你想听的歌手名、歌曲名或视频标题，按下回车即可。

## 3. 日常听歌指南（界面操作）

ting 的界面设计遵循**单视图极简**理念：没有弹窗遮挡，没有闪屏清屏，全部操作通过直观的键盘单键完成。

### 3.1 搜索、选歌与基本控制

当你进入歌曲列表后，最常用的几个键：

| 按键 | 功能 | 说明 |
|---|---|---|
| `↑` / `↓` 或 `j` / `k` | 上下选歌 | 就像用 vim 或日常翻页一样自然 |
| `Enter` (回车) | 播放选中的歌曲 | 后台即刻起播，界面完全不卡顿 |
| `Space` (空格) | 暂停 / 继续 | 随时静音或恢复 |
| `s` | 停止播放 | 完全停止当前声音 |
| `-` / `=` | 音量 - / + | 每次微调音量 |
| `[` / `]` | 快退 10 秒 / 快进 10 秒 | 方便跳过前奏或反复回味 |
| `q` | 退出并停止 | 退出 ting 并自动干净停止音乐 |
| `Q` | 退出并保持 | 退出 ting，音乐在后台继续播放（可用 ting-play 或下次 ting 接管） |

### 3.3 切换平台：YouTube / B站 / 网易云随心换（`e`）

想听不同平台的歌曲？按下 **`e`** 键即可！
- 在 Bilibili 搜索周杰伦现场？
- 一键按 `e`，原地直接切换到网易云音乐检索同一首歌的录音室版本；
- 再按 `e`，切换至 YouTube 检索世界各地的现场或高清 MV；
- 无需重新输入搜索词，ting 会自动用当前关键词重新向新平台检索。

---

### 3.4 播放模式与循环设置（`r`）

按 **`r`** 键可以在以下三种模式之间轮换：
1. **`off`（单曲播放）**：当前这首歌播完后停止，安静不打扰；
2. **`seq`（顺序播放）**：从当前光标位置开始，自动按顺序依次播放后续所有歌曲；
3. **`one`（单曲循环）**：当前歌曲播完后自动重头再播，无限循环。

此外，按 **`v`** 键还可以切换视音频模式：
- `audio`：纯音频模式（省流省带宽，写代码首选）；
- `video`：高清视频模式（弹出视频播放窗口）；
- `fast`：快速低缓冲视频模式。

---

### 3.5 探索多 P 视频与歌曲章节（`c` / `i`）

- **遇到 B 站合集 / 专辑多 P 视频**：
  光标停在该视频上，按一下 **`c`** 键，界面会自动展开所有分 P（如 P1、P2、P3...）。挑选想看的那一集回车起播！再按一次 `c` 原路返回。
- **遇到长视频 / 演唱会完整录屏**：
  如果视频内置了章节信息，光标停在该行按 **`i`** 键，界面会把时间段变成章节列表（如 `00:00 -> 03:20 第一首`）。直接在对应章节按回车，瞬间精准跳转起播！再按一次 `i` 原路返回。

---

### 3.6 歌单管理：收藏、自建与编辑（`a` / `b` / `d`）

碰到喜欢的曲子想存下来？

1. **收藏歌曲（`a`）**：
   在任意歌曲上按 `a`，界面会提示选择或输入歌单名称（例如输入 `chill`）。歌曲立刻被妥善保存。
2. **浏览歌单（`b`）**：
   按 `b` 键即可浏览你的所有歌单。光标移至想听的歌单按回车打开，再按回车即可播放里面的歌曲。
3. **从歌单移出（`d`）**：
   在歌单浏览视图中，看某首歌不顺眼？按 `d` 立刻移出，不再弹确认。手滑了？提示行上写着
   `z 撤销` 的这 3 秒内按 **`z`**，那首歌原样回到原位 —— 正在播的那首也不会被打断。
   `D`（删整张歌单）、`R`（改名）、`a`（加入）以及队列里的 `+` / `x` / `X` 都一样能用 `z` 撤回。
   移出最后一首时歌单会留着（0 首），要删它用 `D`。
4. **返回主搜索列表**：
   在歌单界面随时再按一下 **`b`**，瞬间回到刚才的搜索结果页面，丝滑无残留。

### 3.8 实时过滤与粘贴链接智能识别（`/` 与 粘贴）

- **即打即搜过滤（`/`）**：
  在歌曲很多的列表里，按键盘上的 `/` 键，界面下方会变成过滤框。直接敲入英文字母或汉字关键字，列表会实时响应筛选，按 `Esc` 退出过滤。
- **直接粘贴网址与分享链接**：
  如果你在浏览器或 App 中看到好听的视频、单曲或歌单（支持 YouTube / B站 / 网易云网页链接及带文案的分享链接），直接在 ting 界面中（主列表、`/` 过滤框或 `n` 搜索框中均可）按键盘 **`p`** 键（Vim 粘贴）、**`Ctrl+V`** 或系统粘贴快捷键（`Cmd+V` 或 `Ctrl+Shift+V`）：
  - 粘贴的是**单曲链接**：ting 会自动解析该歌曲并高亮展示在列表中（按 `b` 键可原路返回之前的搜索），按回车立即开播；
  - 粘贴的是**歌单 / 合集链接**：ting 会自动为你展开整张歌单全部条目（按 `b` 键可原路返回之前的搜索）！
  - 自动剥离手机端分享自带的标题外壳（如 B 站 `【视频标题】`、网易云 `分享单曲:` 等文案），智能提取精准网址。

## 4. 进阶玩法：后台听歌与命令行控制

如果你喜欢把听歌彻底当成系统的背景音，或者希望在脚本里控制音乐，ting 提供了极简的后台命令行工具 `ting-play`。

### 4.1 终端关闭也能听：后台脱离播放（`ting-play -d`）

想要音乐在后台静默播放，把当前终端窗口关了也不受影响？
使用带有 `-d`（detach）参数的命令：

```sh
# 播放网易云单曲
ting-play -d -- "https://music.163.com/song?id=1824020871"

# 播放 B 站视频音频
ting-play -d -- "https://www.bilibili.com/video/BV1xx411c7mD"
```
敲下回车后命令立刻返回，音乐在后台自动开始播放，终端完全释放给你干别的事！

> **暖心小设计**：如果你在后台开着 `ting-play -d`，然后再打开 `ting` 界面，`ting` 会**自动发现并接管**后台正在播放的声音；关掉 `ting` 界面时，系统也不会错误杀掉你原本就在听的这首歌！

---

### 4.2 查状态、调音量与切歌

想在命令行控制后台的音乐？无需打开界面，直接敲命令：

```sh
# 1. 看看后台在放什么歌、当前播了多少秒
ting-play --status

# 2. 暂停 / 继续
ting-play --pause
ting-play --resume

# 3. 调音量（例如调到 70%）
ting-play --set-volume 70

# 4. 快进 30 秒 / 后退 15 秒
ting-play --seek +30
ting-play --seek -15

# 5. 彻底停止播放
ting-play --stop
```

---

### 4.3 翻阅收听历史（`ting-history`）

ting 会在本地轻量记录你听过的内容。你想找回刚才听过但忘了名字的旋律？

```sh
# 查看最近听过的 10 首歌曲
ting-history --ls -n 10
```

甚至可以直接用一行管道，把你最近听过的 20 首歌重新做成播放队列再放一遍：
```sh
ting-history --ls -n 20 -j | ting-play -d --queue -
```

### 4.4 边听边看：终端里的音频可视化（`-f viz`）

想让终端变成一台小小的音响？加上 `-f viz`，ting 会把音乐画成一幅随声音跳动的图：

```sh
# 一边听，一边在终端里看频谱跳动
ting-play -f viz -- "https://music.163.com/song?id=1824020871"
```

按 `q` 退出，音乐和画面一起结束。

**两种画法，挑你顺眼的那种。** 写进 `~/.config/ting/config`：

```ini
# bars = 频谱柱状图（默认，窄终端里最好认）
# wave = 声音波形
TING_VIZ_STYLE=bars
```

**颜色也能自己挑。** 默认是青色，可以换成任何你喜欢的颜色：

```ini
# 可以填颜色名（cyan、magenta、green、yellow、orange、white…）
TING_VIZ_COLOR=magenta
```

也可以只在这一次换个颜色，配置文件不用动：

```sh
ting-play --viz-color green -f viz -- "URL"
```

想指定精确的颜色，用十六进制。**注意这里有个坑**：

```ini
# ✅ 在配置文件里，十六进制必须写成 0x 开头
TING_VIZ_COLOR=0xff6188

# ❌ 写成 #ff6188 不会报错，但它会被当成注释整行吃掉，颜色悄悄变回青色
```

（`#` 在配置文件里是注释符号，所以 `#ff6188` 从 `#` 开始就被丢掉了。命令行的 `--viz-color '#ff6188'` 倒是可以，因为它不经过配置文件。）

**三个小提醒**：

1. 可视化要占着当前终端画画，所以它**不能和后台播放 `-d` 一起用**，也不能和 `-j` 一起用；
2. 界面里按 `v` 轮换的是 `audio / video / fast` 三档，**可视化只能从命令行开**；
3. 颜色名拼错了不会报错 —— ffmpeg 认不出来就用它自己的默认色画，所以画面颜色不对时，先检查拼写。

## 5. 个人偏好定制：配置属于你的 ting

### 5.1 自动记住你的操作（就地写回）

在 `ting` 界面中，你的每一次偏好调整都不需要手动改文件！
例如你在界面里把主题切成了 `nord`，音源切成了 `bili`，音质切成了 `high`，退出时 **ting 会自动就地保存到你的用户配置文件中**。下次启动时，依然是你熟悉的配置。

### 5.2 配置文件在哪里？

你的个人配置文件位于：
```
~/.config/ting/config
```
*(如果没有该文件，可以直接新建一个)*。

### 5.3 常用配置项推荐

使用你喜欢的文本编辑器打开 `~/.config/ting/config`，加入以下常见设置：

```ini
# 设置默认启动音源：bili（B站）、ne（网易云）、yt（YouTube）
TING_DEFAULT_ENGINE=bili

# 设置默认主题（可填 minimal, tokyonight, nord, gruvbox, catppuccin 等）
TING_THEME=nord

# 默认界面语言：zh（中文）或 en（英文）
TING_LANG=zh

# 默认音质档位：auto（自动）、medium（中等）、high（高品质）
TING_PLAY_QUALITY=high

# 启动搜索结果数量
TING_SEARCH_RESULTS=25

# 音频可视化（-f viz）的画法与颜色
TING_VIZ_STYLE=bars
TING_VIZ_COLOR=magenta
```

### 5.4 解锁更高音质：关联浏览器登录凭据

部分音源（如 B 站 1080P/高码率音频、网易云等）对于游客用户只提供标准音质。如果你在常用浏览器中已经登录了对应网站账号，ting 可以直接无感知借用浏览器的登录状态，解锁更高音质：

在 `~/.config/ting/config` 中追加：
```ini
# 三个音源解析时都借用 Chrome 的登录状态（出厂默认就是 chrome；也可以填 safari, edge, firefox 等）
TING_COOKIE_BROWSER=chrome
```
*(如果不希望读取浏览器凭据，可设为 `none`)*。

## 6. 小白常见问题与排错（FAQ）

### Q1: 运行播放后听不到声音？
**解答**：
1. 请先检查系统静音状态，或者在终端运行 `mpv` 播放一个本地音频文件测试系统输出是否正常；
2. 尝试调大音量：在 ting 界面中按键盘 `=` 号调大，或在命令行运行 `ting-play --set-volume 90`；
3. 如果是 Linux 用户，请确保系统已配置好 PipeWire 或 PulseAudio 声音服务。

---

### Q2: 为什么有些歌曲播放不了？
**解答**：
1. **网易云 VIP 限制**：网易云音乐的大量歌曲受版权保护，游客账号仅提供 30 秒试听。建议在配置文件中配置 `TING_COOKIE_BROWSER=chrome` 关联已登录账号；
2. **地区或网络受限**：YouTube 音源需要稳定的国际互联网连接。如果连接受限，建议在界面中按 `e` 切换到 B 站或网易云音源。

---

### Q3: 界面字符有些错位、乱码或对齐不齐？
**解答**：
这是由于部分终端字体的“中文双字符宽度（Ambiguous Width）”渲染设定引起的：
- 推荐使用支持现代特性的终端模拟器（如 iTerm2、Ghostty、Kitty、WezTerm 等）；
- 在终端配置中将字体设置为支持 Nerd Font / 宽字符的标准等宽字体；
- 或者在 ting 配置文件中加入 `TING_ASCII=1`，开启绝对对齐的纯 ASCII 模式。

---

### Q4: 怎么一键停止所有正在后台响的音乐？
**解答**：
如果你之前在后台启动过多次播放，想让所有声音立刻安静下来，只需在终端敲入：
```sh
ting-play --stop --all
```
所有 ting 相关的播放器会瞬间干净关闭。

---

### Q5: 怎样完全卸载？
**解答**：
- 如果通过 Homebrew 安装：
  ```sh
  brew uninstall ting
  ```
- 如果通过源码软链接安装：
  删除 `~/.local/bin/` 下的软链接，并根据需要删除 `~/.config/ting` 配置目录与 `~/.local/state/ting` 播放历史状态即可。
