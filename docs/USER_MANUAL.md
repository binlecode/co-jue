# ting 用户使用手册：人机协同交互指南

**ting-gen-2 没有独立的图形界面（GUI）或终端菜单（TUI）。你的对话窗口（或语音流）就是唯一的交互界面。**  
你不需要记任何命令行参数，也不需要看底层 JSON。本手册专门教你：**如何用最自然的话让 Agent 帮你找内容、研读长视频与调度端侧声音。**

---

## 核心心智模型 (Mental Model)

```
        人类 (你) ----------------(自然语言对话)-----------------> AI Agent (你的伙伴)
            |                                                           |
            | (紧急暂停/直接切歌)                                         | (调度微外设)
            v                                                           v
  物理按键 (AirPods / F8 键)                                     ting (后台无头 mpv)
   [ 0ms 延迟 · 零 Token 开销 ]                                   [ 本地声卡 · 毫秒级控制 ]
```

- **复杂意图找 Agent**：“放点适合写代码的慢歌”、“总结这期演讲第 15 分钟说了什么”、“把重点记进知识库”；
- **肌肉记忆找物理键**：电话来了、想立刻静音？直接轻捏一下 AirPods 耳机柄或按键盘媒体键（F8），**0ms 瞬间暂停，跳过大模型，不消耗任何 Token**。

## 常用交互场景与实操话术

### 场景 1：日常专注伴随听歌

| 你的意图 | 你可以直接对 Agent 说 | Agent 会如何响应与呈现 |
|---|---|---|
| **找歌放歌** | “放点写代码的 Lo-Fi”<br>“来首周杰伦的晴天” | Agent 自动找稳定源并在后台播放，在对话框贴出一张 **2 行极简卡片**：<br>`**正在播放** · 晴天 — 周杰伦 · 网易云`<br>`按耳机即可暂停，说“暂停 / 音量 40”亦可控制` |
| **放特定链接** | “播放这个：`https://...`” | 自动启动后台单实例播放，如果之前有歌在播会自动平滑替换 |
| **调音量** | “声音大点 / 音量调到 40” | 毫秒级调节物理音量 |
| **切歌 / 停播** | “换一首” / “停掉音乐” | 停播并彻底退出后台播放器，不留僵尸后台 |

### 场景 2：长视频/播客精准研读与问答

当你面对一个 1~3 小时的技术演讲、播客或大会录播时：

```
                    你给出一个长视频链接
                             |
             +---------------+---------------+
             v                               v
       【先看全局路标】                【再看局部细节】
   “这个视频有几部分，讲了啥？”     “第 15 分钟作者说了什么？”
             |                               |
             v                               v
    Agent 只花 <100 Tokens           Agent 只切片拉取目标区间
   几秒内呈现 Chapters 章节大纲        提取逐字原声与跳转超链接
```

#### 实操对话示例：

1. **问大纲**：
   > **你**：“*看看这个演讲主要分哪几块？*”  
   > **Agent**：“*为您提取了章节地图：*  
   > *- 00:00 架构总览*  
   > *- 14:45 KV Cache 动态分页压缩*  
   > *- 28:10 基准测试性能对比*”

2. **问细节（精准原话引用）**：
   > **你**：“*第 15 分钟关于 KV Cache 压缩，作者具体怎么论证的？*”  
   > **Agent**：“*核心结论是静态剪枝在大上下文下必定精度坍塌；关键逐字原话：*  
   > *- `[15:12]` [“Static pruning inevitably destroys recall beyond 32k tokens.”](https://youtube.com/watch?v=...&t=912s)*  
   > *- `[16:40]` [“Our dynamic paging mechanism drops memory by 65%.”](https://youtube.com/watch?v=...&t=1000s)*”

3. **知识沉淀入库**：
   > **你**：“*把上面的论点和大纲记入 co-library 知识库*”  
   > **Agent**：自动整理成标准事实卡片，沉淀为知识资产。

### 场景 3：边听边打断的时空追问（“刚才那句讲了啥？”）

当你一边干活一边听背景技术演讲，走神了 10 秒钟时：

```
[听到关键术语走神] 
       |
       v
  你：“停一下，刚才那句话说了什么？”
       |
       +--> 1. Agent 立即暂停播放 (播放头锁定在当前秒数)
       +--> 2. 自动提取你刚才听到的前 15 秒逐字字幕
       |
       v
Agent：“刚才的原话是：‘机器人的具身智能，本质是端侧物理感知闭环能否在 20ms 内对抗扰动。’
       需要帮您倒回去 15 秒重新听一遍吗？”
       |
       v
  你：“倒回去听”
       |
       v
Agent 自动后退 15 秒并恢复播放，音频无缝重新流转。
```

## 异常与自愈指南

当遇到以下情况时，Agent 会自动自愈并体贴地提供建议：

| 现象 / 场景 | 实际原因 | Agent 会如何自愈并建议 |
|---|---|---|
| **B 站视频无法提取逐字稿** | B 站未公开原声音轨字幕 | Agent 绝不报错，会自动降级：“*该视频无公开原声字幕，但我已为您准备好章节地图，您可以直接听哪一部分*” |
| **网易云纯音乐 / 伴奏** | 纯器乐无歌词 | Agent 会主动告知：“*这是一首纯音乐（无歌词），但我可以为您在音箱直接播放*” |
| **链接打不开 / 不支持** | 给了 QQ音乐或非公开链接 | Agent 会提示：“*目前支持网易云、YouTube 与 B 站，建议您给我歌名，我来帮您定向查找*” |

## 终极总结口诀

- **听歌动嘴**：想听什么直接说，2 行卡片看着爽；
- **暂停动手**：捏按耳机最灵光，零秒静音不用等；
- **长篇问点**：不用通篇读字幕，报个分钟 Agent 抓；
- **沉淀知识**：关键证据随手存，自动归入知识库。
