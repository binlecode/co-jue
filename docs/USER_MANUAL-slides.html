01 / PARADIGM SHIFT

别再给播放器写客户端了

进入「可抛弃客户端软件 (Post-App Paradigm)」时代：The Agent is the UX。你的对话流就是唯一的交互呈现层。

传统客户端模式 (App-Centric) 割裂心流

• 切屏与注意力税：打开专有窗口、翻列表、点鼠标，强行打断思考与 Coding 节奏；

• 大模型视听黑盒：独立播放器对 Agent 闭门造车，大模型无法查章节、无法取证据，只能当愚蠢的“音箱开关”；

• 客户端应用臃肿：本地堆砌 UI 排版、推荐算法、播放记录与本地数据库，沦为重度功能孤岛。

Agent 微外设模式 (Agent-Centric) 细腰直通

• 对话流即界面：动嘴说意图，Agent 负责搜播、呈现 2 行极简 Markdown 卡片，播放头毫秒级同步；

• 视听感知器官（输入端）：秒出章节目录（<100 Tokens）、靶向提取原声逐字证据（<500 Tokens）；

• 端侧声卡驱动（输出端）：单实例后台无头流转，AirPods / 媒体键 0ms 硬件直通急停。

02 / ACOUSTIC CONTROL LOOP

脑管语义编排，手管物理急停

绝不把所有操作都压给大模型。复杂的理解交给语言通道，本能的反射交给硬件直通。

人类 (你) -----------------( 自然语言对话流 )-----------------> AI Agent (你的伙伴) | | ^ | (紧急暂停 / 即刻静音) | (调度外设) | (主动事件信标) v v | events (曲毕/换章) 物理按键 (AirPods 耳机柄 / 键盘 F8) -----------------------------> jue (后台无头单实例 mpv) [ 0ms 延迟 · 零 Token 开销 ] (原生直通硬件急停) [ 本地声卡 · 毫秒级 Unix Socket ] | +---> 触发 paused 即刻反哺 Agent
下行直通：硬件逃生口（手） 0ms 响应

电话打入或同事走来讨论？千万别等大模型推理网络往返。

轻捏一下 AirPods 耳机柄或按键盘 F8 键，--input-media-keys=yes 原生直通底层声卡，瞬间静音，不消耗任何 Token。

上行感知：对称声学反哺（脑） 毫秒级推流

手捏耳机暂停后，底座通过 Unix Socket 异步广播 paused 事件。

外部语音助手（co-s2s）在同一毫秒获知物理状态翻转，即刻切入倾听态，人机默契无缝对齐。

03 / VALUE MATRIX

听歌只是附赠品，证据才是主战场

传统播放器以“出声”为终点；jue 的万倍杠杆在于：将数小时长音频瞬间转化为可核验的事实原件。

Tier 1: 认知杠杆 ★★★★★ 极高

1. 长视频分章解构与点播
<100 Tok 秒出全局路标，选定章节精确入耳。

2. 声称级事实核查与引用
靶向切片提取原声原话，带秒级 &t= 溯源链接。

3. 实时打断与时空追问
走神/暂停瞬间锁定播放头，抓出原话并重听。

4. 媒体资产沉淀至知识库
瞬态流媒体提炼为终身可检索的客观知识资产。

Tier 2: 专注心流 ★★★★☆ 高频

5. 专注伴听、播控与续播 DJ

网易云 LRC 逐行对齐，外语听力与原声语法精读。

05 / SCENARIO 02 & 03 · VERBATIM EVIDENCE

拒收二手总结，直取声称原件

模型自言自语总结是幻觉的温床。回答“作者说了什么”，必须拿出带秒级时间戳的逐字原话。

场景 2：声称级事实核查 < 500 Tokens

你：“*第 15 分钟关于动态分页，作者具体怎么说的？引用原话。*”

$ jue transcript <url> --range 14:00-17:30
> [15:12] "Static pre-allocation causes 70% memory waste."
> — 来源超链接：https://...&t=912s

• 相交区间裁剪：只切片目标 3 分钟窗口，杜绝全文读入撑爆 Context；

• 防机翻污染：强制锁定原语种自动语音（en-orig）或人工原稿。

场景 3：实时打断与倒带重听 时空解耦

你：“*停一下，刚才那句话说了什么？*”

1. 暂停 mpv ➔ 锁定播放头秒数 (如 845s)
2. jue transcript --range 830-850 提取前后原话
3. 回答用户刚才原句，询问是否倒回去听
4. 用户确认 ➔ jue control seek -15 恢复流转

• 时空解耦：播放头时间戳与原文字幕时间轴实时对齐，彻底终结听课走神痛点。

06 / SCENARIO 07 · FRAME PERCEPTION

视觉破壁：告别“盲人摸象”，直视架构拓扑与代码屏幕

长程技术演讲的关键事实大量残留在 PPT、白板与终端上；端侧单帧感知让 Agent 真正睁开双眼。

纯文本大模型的“认知断层” 盲人摸象

演讲者口述：“大家请看这张架构图，左侧调度器直接穿透网络栈连入环形缓冲区...”

❌ 纯文本 Agent 困境：
口述中只有一句“如图所示”，大模型陷入信息黑洞，开始基于通用预训练产生二手幻想。

💡 Case 1 真实战例 (3Blue1Brown)：
口述通篇仅提及 “specifically a number between zero and one”，未念出具体数字；纯文本模型在数值追问上全军覆没。

• 断层根因：高密度技术信息在音频轨与视觉轨之间天然非对称分布。

jue frame 视听融合去幻觉 法庭级证据

Agent 执行：jue frame <url> --at 180 --width 960

⚡ 毫秒级瞬态抽帧：
- 冷启动 2.5s / 热命中 0.5s（纯 Go 32 分片直链缓存）
- 极轻产物：单帧仅 16.2 KB，双边等比外框约束锁定在 ~690 Tokens

👁 Agent 睁眼直视 (read_image)：
- 准确读取浅蓝圆圈内的浮点数 0.8
- 精确提取 LaTeX 排版：Neuron → Thing that holds a number
- 双轨交付：人类端交付带 &t=180s 外网直达链接，彻底规避 Web GUI 裂图

• 闭环收益：以几十 KB 的极简开销，换取 100% 确定性的声画互验事实证据链。

08 / SCENARIO 05 · AUTONOMOUS BEACON

告别轮询：事件信标与零开销续播

如何当好自动续播 DJ？坚决不搞死循环轮询。mpv 原生 IPC 广播直连，曲毕瞬间平滑接力。

专注伴听卡片 2 行极简

“来首周杰伦的晴天。”
“放一下本地录音 tmp/meeting.wav”

呈现 2 行极简卡片，绝不刷屏：
正在播放 · 晴天 — 周杰伦 · 网易云
按耳机即可暂停，说“换一首/快进”亦可控制

支持番茄钟到点自动停止。

续播 DJ (零轮询) Event Beacon

“放两首轻音乐，连续伴随播放。”

起播 Track 1 后，Agent 执行：
jue events --until track_ended 挂起等待。

放毕瞬间捕获 eof，即刻平滑起播 Track 2，0 轮询开销，曲目无缝衔接。

毫秒级播控穿梭 精准时空

• “跳过广告” ➔ seek +90
• “倒回去听” ➔ seek -15
• “跳到24分” ➔ seek 24:30
• “音量调到40” ➔ volume 40
• “播到哪了” ➔ status 探查

09 / RESILIENCE & CONTRACT

绝不向智能体抛出未经处理的异常

真实网络与多媒体底层极其脆弱。四级退出码与机器信封确立优雅降级梯级。

四级确定性退出码契约 Machine Envelope

• 0 (Success)：正常起播、播控成功、事件捕获命中；

• 1 (Usage Error)：参数格式错、非媒体 URL（引导模型自纠错）；

• 2 (Infra Failure)：依赖缺失、0700 目录安全拦截、网络中断；

• 4 (Business Not Ready)：媒体无字幕 (unavailable)、未播放喊控制 (not_playing)、事件超时 (timeout)。

智能体全自动自愈与降级 优雅降级

• B 站视频无公开字幕 (Code 4)：自动降级为提取 Chapters 章节大纲；

• 网易云纯音乐无词 (Code 4)：主动告知为器乐纯音乐，照常起播不报错；

• 非法参数 / 坏链接 (Code 1)：输出单行 JSON，引导用户口述歌名代查；

• 未播放喊快进 (Code 4)：友好提醒“当前没有在放，请直接吩咐歌名”。
