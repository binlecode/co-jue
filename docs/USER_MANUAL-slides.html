进入「可抛弃客户端软件 (Post-App Paradigm)」时代：The Agent is the UX。你的对话流就是唯一的交互呈现层。

旧世界：24,000 行的双向妥协 架构死锁

Robustness · 异常自愈与降级艺术

四级退出码契约：绝不抛出未经处理的异常

真实网络环境极其脆弱（无字幕、纯音乐、断网）。ting 建立严格降级梯级，保证 Agent 永远能体贴应对。

四级确定性退出码契约 标准协议
0 Success 命令执行成功，标准单行 JSON
1 Usage Error 参数格式非法、缺少 URL、时间格式错
2 Tool/Net Fail 缺失 mpv/yt-dlp、底层网络中断
4 Not Ready 业务未就绪 (无公开字幕 unavailable, 空闲时发控制)

所有命令输出一律强制为单行紧凑 JSON，严格保证 Agent 工具调用的解析安全性。

Engineering Invariants · 极致工程底线

无依赖、单静态二进制、零内存泄漏

面向系统工程师的严苛底线：保证常驻进程绝对可靠、权限绝对收容、并发绝无竞态。

纯 Go 标准库与单静态

全仓代码纯 Go 标准库实现，零 cgo，零外部第三方包，编译为单一静态二进制。外部仅锁定 mpv 与 yt-dlp 两个系统原语。

0700 权限与状态安全隔离

运行时 Socket 严格收容在 $TMPDIR/ting-<uid>/，权限必须为严格 0700 且属主等于自身 UID，拒收任何符号链接与宽权限目录。

request_id 解交错与无僵尸守护

单套接字多路解耦异步事件；并发起播通过 Flock 文件锁安全互斥；stop 下发后 mpv 200ms 内优雅退出，零僵尸残留。
